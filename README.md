# help-desk-oop

Первая практика по Java, консольный Help Desk на ООП.

В model лежат заявки и пользователи, в service уведомления и TicketService, в repository хранятся заявки.

Я запускаю из терминала командой `mvn compile exec:java -Dexec.mainClass=helpdesk.Main`

Ещё можно открыть папку в VS Code с Extension Pack for Java и нажать Run над main в Main.java. Java нужна 17.
